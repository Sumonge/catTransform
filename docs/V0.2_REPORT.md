# catTransform v0.2 本地构建报告

## 范围

- 安装包分为精简版、完整版和独立的离线 EPUB 组件包。精简版保留 .NET、Windows App SDK、字体和所有非 EPUB 转换能力；完整版内置 Java 与 EPUBCheck。组件包安装在当前用户的 LocalAppData/catTransform/components/epub，程序自动识别，不下载运行时。
- PDF 支持可选择文字的输入，默认输出可搜索的文字重排版 PDF，也可选择 UTF-8 TXT。扫描件无文字层时拒绝转换；不提供 OCR 或保留原 PDF 页面版式的输出。
- DOCX：多 run 的长度变化若能逐 run 独立转换且结果与整段一致，则保留各 run 样式继续转换；无法可靠映射的跨 run 长度变化仍拒绝。
- EPUB：段落、标题等结构中跨内联 XML 节点的等字符数转换可以保持标签边界；无法可靠映射的长度变化仍拒绝。输出继续通过 EPUBCheck 验证。
- 将 System.Formats.Cbor 锁定到 8.0.2，消除构建时针对 8.0.0 的漏洞告警。

## 本地构建与体积

| 文件 | 约 MiB |
| --- | ---: |
| catTransform-0.2.0-win-x64-full.exe | 124.2 |
| catTransform-0.2.0-win-x64-lite.exe | 72.8 |
| catTransform-0.2.0-epub-addon-win-x64.exe | 53.5 |

精简版比同版本完整版的下载体积小 41.4%。如同时需要 EPUB，直接下载完整版比精简版加组件包的总下载量略小。此测量是安装包文件大小，不代表安装后磁盘占用；从旧完整版直接升级到精简版时，旧安装目录中的组件可能仍需通过卸载旧版来释放空间。

- dotnet test tests/CatTransform.Tests --no-restore：77/77 通过，含 PDF→PDF 重排、PDF→TXT、无文字层 PDF、DOCX 多 run 和 EPUB 内联节点回归。
